# New Dawn runtime assets

Everything here is loaded by the renderer from `<gNewDawn.Assets.Path>/<pack>/` (default `assets/newdawn` beside the
executable). The build copies this directory next to the game and `install` ships it, so players need nothing else.
Every file is redistributable and carries its licence; see `docs/licenses/THIRD_PARTY_ASSETS.md` for the full table.
Nothing here is derived from the game's own data (those maps are generated on the player's machine).
